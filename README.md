Customer Churn Analysis

Project Overview

This project analyzes customer churn data using Microsoft Excel and Power BI. It explores customer attrition patterns, churn reasons, customer age demographics, and data consumption behavior to support data-driven business decisions.

Project Objectives

Measure the overall customer churn rate.
Identify the most frequently reported reasons for customer churn.
Compare churn rates across data consumption categories and unlimited data plan usage.
Analyze customer distribution and churn rates across age groups.
Present key performance indicators and findings through a visual dashboard.

Tools Used

Microsoft Excel: Data exploration, data organization, and supporting analysis.
Microsoft Power BI: Data visualization, KPI reporting, and dashboard development.

Key Metrics

Total Customers: 6,687
Churned Customers: 1,796
Churn Rate: 26.86%

Dashboard Insights

Churn Reasons: Identifies the most common reasons for customer churn.
Data Consumption: Compares churn rates across data consumption groups and unlimited data plan usage.
Age Analysis: Examines customer counts and churn rates across age groups and demographics.
